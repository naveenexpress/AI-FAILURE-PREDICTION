# Equipment Failure Prediction - Frontend

Modern, high-performance web dashboard for industrial condition monitoring, sensor telemetry visualization, and AI failure risk analytics.

## Tech Stack

- **Framework**: React 19 with TypeScript
- **Styling**: Tailwind CSS v4
- **Charts & Visualization**: Recharts
- **Icons**: Lucide React
- **Build Tool**: Vite 8 & TypeScript compiler

## Available Scripts

In the `frontend` directory, you can run:

```bash
# Install dependencies
npm install

# Start development server on port 5173
npm run dev

# Run TypeScript type check and production bundle build
npm run build

# Run Oxlint linter
npm run lint

# Preview production build locally
npm run preview
```

## Environment Configuration

Copy `.env.example` to `.env`:

```env
VITE_API_BASE_URL=http://localhost:8000/api/v1
```
